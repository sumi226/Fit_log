1. Project name :- FITLOG 

2. Short Description

FITLOG is a modern workout library and daily fitness planning web application. Users can explore workouts, view detailed exercise information, sort exercises by different metrics, create a daily workout plan, save workouts for later, and track their planned exercises through a clean and responsive interface.

3. Technologies Used
Next.js — React framework with App Router
TypeScript — Type-safe development
Tailwind CSS — Responsive and utility-first styling
Lucide React — UI icons
REST API — Dynamic workout data
LocalStorage — Persisting today's plan and saved workouts


4. 5 Key Features

=>  Workout Library :- Browse a collection of workouts with images, muscle groups, equipment, difficulty, duration, calories, and ratings.

=> Workout Details :-  View complete workout information including equipment, sets, reps, duration, calories, rating, description, and step-by-step instructions.

=> Sorting :- Sort workouts by Duration, Calories, or Rating using the Sort By dropdown.

=> Today's Plan & Saved Workouts :- Add workouts to today's plan with a maximum of five exercises and save workouts for later.

=> Live Plan Tracking :-
Track exercise count, total minutes, and calories on the My Plan page, with live navbar counters, remove/complete actions, and toast notifications.
